# 테마 색상 근거

확인일: 2026-09-16. 교수님 사이트의 실제 화면 스타일과 대학의 공식 웹 색상 가이드를 기준으로 구성했습니다. 색상값과 배색 원칙을 Folio의 공통 레이아웃에 적용한 것으로, 원본 사이트 전체를 복제한 템플릿은 아닙니다.

## 실제 값과 적용 방식

- **세이지**: 원본의 회녹색 바탕, 어두운 제목, 초록 버튼 글씨, 테라코타 소제목 색상을 확인했습니다. 보조 글자는 `#566158`, 구분선은 `#D4DBCC`입니다. 원본 버튼의 `rgba(58,104,80,.13)`을 바탕색 위에 합성한 `#D7DFD6`를 Folio의 연락처·보조 면에 사용합니다. 테라코타는 본문 대비를 확보하기 어려워 Folio에서는 장식 선에만 사용합니다.
- **네이비**: 흰색·연회색과 Yale Blue를 함께 쓰는 공식 원칙을 적용합니다. 보조 배경 `#F9F9F9`, 글자 `#222222`·`#4A4A4A`, 구분선 `#DDDDDD`는 [Yale UI 색상 가이드](https://yaleux.github.io/yaleui/styleguide/colors.html)의 값입니다.
- **딥레드**: Cardinal Red, 흰색, 검정, 쿨그레이로 구성된 공식 기본 팔레트를 사용합니다. 본문 `#2E2D29`, 보조 글자 `#53565A`, 보조 면 `#EAEAEA`와 선 `#D5D5D4`도 같은 가이드에 명시된 값입니다. 이전의 분홍빛 배경은 사용하지 않습니다.
- **퍼플**: 흰색이 화면의 주된 색이어야 한다는 공식 지침을 따릅니다. 보라색은 제목·링크·선택 버튼·장식 선에 적용합니다. 본문 `#342F2E`, 보조 글자 `#716C6B`, 구분선 `#D8D6D6`은 가이드의 Rich Black 명도 단계입니다. 보조 면도 흰색입니다.
- **차콜**: 원본 화면의 흰 바탕, 차콜 제목, 파란 링크, `#FBFBFB` 보조 영역을 확인했습니다. 본문 `#333333`, 보조 글자 `#585858`도 화면에서 확인한 값입니다. Folio의 목록 구분선 `#D6D6D6`은 본문색을 흰색 위에 20%로 합성한 적용값이며 원본에서 직접 추출한 값은 아닙니다.

## Folio에서의 역할

소개 영역은 전체 페이지와 같은 바탕을 사용합니다. 제목 색과 링크 색, 장식 색을 별도 역할로 나누어 세이지의 테라코타와 차콜의 파란 링크까지 표현합니다. 연락처·파일 첨부 등의 보조 면에는 각 팔레트의 보조 배경을 사용합니다. 테마 선택 미리보기, 프로젝트 카드, 편집·미리보기, 내보낸 HTML에 동일한 역할을 적용합니다.

기존 저장 ID `forest`, `navy`, `burgundy`, `plum`, `charcoal`을 유지하므로 기존 프로젝트도 각 대응 팔레트를 사용합니다. 폰트 설정과 작성 내용은 변경하지 않습니다.

본문·보조 글자·제목·링크의 배경 대비와 선택 버튼의 흰 글자 대비를 자동 검사합니다. 출처는 이 문서에 보관합니다.
