# 초안 공유와 게시 변경 요약

## 사용 흐름

- 프로젝트 카드 **더보기 → 초안 공유**, 또는 편집기 **미리보기 → 초안 공유**로 진입한다. 게시 창에도 같은 탭이 있다.
- **검토 링크 만들기**는 현재 공개용 HTML과 사진·PDF를 복사한다. 공개 홈페이지의 주소·내용·게시 상태는 바뀌지 않는다.
- 링크 소지자는 로그인 없이 읽을 수 있다. 내부 출처 검토 기록과 편집 화면은 포함되지 않는다. 이번 범위에는 댓글·승인 처리가 없다.
- 7일 후 만료. **현재 내용으로 새 링크**는 토큰과 저장본을 교체하고 이전 링크를 종료한다. **링크 종료**는 즉시 접근을 막고 저장 파일을 삭제한다.
- 편집 이후 기존 링크는 자동 갱신하지 않는다. 편집 상태와 공유 저장본이 다르면 안내한다.

## 서버

기존 PublicationObject에 검토 저장본을 별도 키로 보관한다. 새 서비스나 데이터베이스 마이그레이션은 필요 없다. 기존 게시 연결 복구 별칭도 같은 객체로 접근한다.

관리 경로: `/v1/sites/:id/review` — GET 조회, PUT 생성/교체, DELETE 종료. 기존 Google 인증과 공용 프로젝트 권한 검사를 그대로 거친다. `If-Match`에 기존 토큰 또는 `none`을 보내 동시 변경을 거절한다.

열람 경로: `/review/:id/:token/` — 256비트 무작위 토큰으로 접근한다. 서버에서 만료를 검사하고, Durable Object alarm으로 만료 파일을 정리한다. 저장은 트랜잭션으로 처리하며 큰 파일은 나누어 보관하고 Response 스트림으로 RPC 경계를 통과한다.

페이지·파일에 `no-store`, `noindex`, `no-referrer`를 설정한다. 공개 HTML은 API와 같은 출처 권한을 얻지 못하도록 `allow-same-origin` 없는 sandbox에서 실행한다. 토큰이 포함된 링크를 전달받은 사람은 열람할 수 있으므로 사용자 화면에도 이를 명시한다.

## 게시 비교 기준

공개될 섹션·항목·문구와 파일 내용 해시, 디자인 설정으로 비교 기록을 만든다. 메모·출처 검토 기록, 비활성 언어, 숨긴 섹션은 제외한다. 첨부 원본 대신 해시만 비교 기록에 넣는다. 긴 문구는 앞부분을 표시한다.

배포 성공과 공개 주소 확인이 모두 끝난 후에만 `liveManifest`를 바꾼다. 실패·진행 중에는 이전 공개 버전이 비교 기준이다. 과거 게시에 기록이 없으면 상세 비교 불가 안내를 표시하고 다음 게시부터 기록한다. 공개 `/link` 응답에는 비교 기록을 노출하지 않는다.

## 검증

- Node: 항목 추가·수정·삭제, 소개문 전후, CV 바이트 변경, 언어·순서·숨김, 내부 메모 제외, 게시 성공 전후 비교 기준.
- Workers: 인증·출처 제한, 사이트별 격리, 링크 교체·종료·만료, 파일 정리, 동시 갱신 충돌, 잘못된 업로드 후 기존 링크 보존, 복구된 게시 ID, 1MB 초과 PDF 응답.
- 로컬 브라우저: 카드에서 진입 → 생성 → 로그인 없는 열람 → 영·한 전환 → 새 링크 생성 → 이전 링크 차단 → 종료. 사진 로딩, 작은 화면의 메뉴·가로 넘침, 변경 요약 펼침 확인.
