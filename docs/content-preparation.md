# 자료 준비

새 프로젝트는 이름·소속·언어·참고 주소를 받은 뒤 **프롬프트**부터 열립니다. 이미 자료가 있으면 바로 가져오거나 직접 입력으로 넘어갈 수 있습니다. 기존 프로젝트에서는 편집기 상단의 **자료 준비**를 누릅니다.

1. **프롬프트**: 교수님 이름·소속을 확인하고 공식 주소와 필요한 영역을 선택합니다. 프롬프트를 복사해 사용하는 AI에 전달하세요.
2. **가져오기**: AI가 작성한 MD·TXT 파일(512KB 이하)을 올리거나 답변을 붙여넣습니다. ‘양식 받기’로 직접 작성할 수도 있습니다.
3. **확인**: 실제 페이지 미리보기에서 반영할 내용을 선택합니다. 기존 내용 교체와 확인이 필요한 항목은 기본 해제되어 있으며, 나머지 새 내용은 기본 선택됩니다. 소개·연락처는 요약으로 먼저 보고, 펼쳐서 개별 항목을 선택할 수 있습니다.

새 프로젝트에서 반영을 마치면 **템플릿 선택**이 열립니다. 기본형·소개형·컬러형·연구형을 현재 자료로 비교하고 편집으로 이어갑니다. 중간에 닫아도 홈의 프로젝트 카드에서 자료 준비 또는 디자인 선택을 이어갈 수 있습니다.

준비 중인 입력은 프로젝트별로 현재 브라우저에 보관합니다. Folio가 AI를 직접 호출하거나 자료를 외부로 전송하지 않습니다.

## Markdown 양식

```md
# Folio

## EN / profile
name: Alex Kim
college: Example University
body: |
  Alex Kim studies energy economics.
source: https://example.edu/faculty/alex
checked: 2026-09-16
notes:
review:

## EN / publications
### item-1
year: 2025
topic: Paper title
text: Authors — Journal
doi: 10.1234/example
source: https://example.edu/publications

## KO / awards
### item-1
year: 2024
topic: 수상명
text: 수여 기관
source: https://example.edu/awards
```

- `## EN / 영역` 또는 `## KO / 영역`: 언어와 섹션. 한글은 `KOR`도 인식합니다.
- `### item-1`: 논문·수상·학력 등 목록의 개별 항목. 항목마다 필드를 반복합니다.
- `key: value`: 일반 텍스트. 긴 문단은 `body: |` 아래에 두 칸 들여씁니다.
- `source`, `checked`, `notes`: 관리용 출처·확인 날짜·일반 메모. 기존 양식의 `notes`도 그대로 읽으며 일반 메모로 표시합니다.
- `review`: 사실 확인이 필요한 사항. 항상 펼쳐서 표시하고, 해당 내용은 직접 선택해야 반영됩니다. 공통 메모·확인 사항은 영역 아래에 한 번만 적습니다. 이 관리용 정보는 공개 HTML에 포함하지 않습니다.
- `image`, `pdf`: 필요한 파일의 이름·주소를 기록하는 메모. 파일을 자동 다운로드하지 않으며, 반영 후 페이지에서 직접 업로드합니다.

실제 사용할 수 있는 영역과 필드는 선택한 프롬프트·다운로드 양식에 포함됩니다. 일반 Markdown 문서를 임의로 추측해 배치하지 않습니다. AI 답변의 코드 블록 바깥 설명은 본문에서 제외합니다. 양식 밖의 내용은 안내하며, 인식하지 못한 파일은 수정 프롬프트로 다시 정리할 수 있습니다.

## 기존 내용 보호

빈 필드와 누락된 영역은 기존 내용을 지우지 않습니다. 수상은 수상명·연도·수여 기관을 함께 비교하고, 논문은 DOI를 우선 비교합니다. 제목만 같은 별도 항목을 덮어쓰지 않으며, 기존 항목을 하나로 구분하지 못하면 자동 연결하지 않습니다. 수상 목록에 연도와 수여 기관도 표시합니다. 교체를 선택해도 파일·크기와 제공하지 않은 필드는 유지합니다. 한글 자료를 선택해 적용하면 필요한 한글 페이지를 추가합니다. 숨긴 섹션은 숨김 상태를 유지합니다.

적용 직후 **가져오기 되돌리기**로 복원할 수 있습니다. 이후의 별개 수정은 유지하며, 가져온 항목 자체를 다시 수정한 경우 자동 복원을 멈춰 덮어쓰기를 방지합니다. 되돌리기 기록은 새로고침 전까지 유지됩니다.
