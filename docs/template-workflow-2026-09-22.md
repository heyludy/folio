# 자료부터 시작하는 Folio

## 디자인 계획

- 관리 화면: 화이트 `#ffffff`, 페이퍼 `#f8f9f8`, 차콜 `#2a2a2a`, 그린 `#355b49`, 구분선 `#dfe3df`.
- 글꼴: 관리 화면은 Pretendard. 기본형은 Source Serif 4 / Source Sans 3, 소개형은 Jost / Libre Franklin, 컬러형과 연구형은 Source Serif 4 / Source Sans 3.
- 연구형: 화이트 바탕, 네이비 제목, 회색 구분선. 이름과 소개를 간결하게 두고 연구 분야는 열린 열, 논문·프로젝트는 두 열의 카드로 구분한다. 이미지가 없어도 제목·연도·저널 정보로 완결된다. 모바일은 한 열.

```
프로젝트 이름·소속·언어·공식 URL
              ↓
프롬프트 복사 → 외부 AI → MD 파일 / 답변 붙여넣기
              ↓
출처·반영 항목 확인 → 페이지 생성
              ↓
사진·CV 추가 (선택 · 건너뛰기 가능)
              ↓
[기본형] [소개형] [컬러형] [연구형] (내 자료로 비교)
              ↓
직접 편집 · 사진/PDF → 미리보기 → 게시
```

## 구현 원칙 및 검토

- 내용을 갖춘 상태에서 디자인을 고른다. AI 결과는 출처와 교체 항목을 확인한 다음 반영한다.
- 템플릿 변경은 섹션 순서, 텍스트, 파일, 크기 조정, 프로젝트·게시 연결을 유지한다. 디자인별 색/폰트는 기억한다.
- 새 프로젝트는 자료 준비부터 열고, 닫았다가 다시 열어도 이어갈 수 있다. 기존 프로젝트는 바로 편집한다.
- 템플릿 비교는 현재 자료를 사용한다. 공개 예시는 허은녕 교수님 자료로 네 가지를 제공한다.
- 기존 세 디자인은 유지한다. 연구형은 섹션마다 박스를 반복하지 않고 논문·프로젝트에만 카드를 사용한다.
- 실제 교수님 운영 사이트를 자동 재게시하지 않는다.

## 검증

- 209개 앱 검사, 게시 서버 검사 12개, Worker 배포 사전 확인 및 production build 통과.
- 로컬 브라우저에서 이름·소속·한영 선택 → 프롬프트 복사 → 답변 붙여넣기 → 14개 항목 반영 → 현재 자료로 템플릿 비교 → 연구형 적용 → 소개형 변경 확인.
- 준비 중인 답변을 닫았다가 프로젝트 카드에서 복구하는 경로, AI를 건너뛰고 직접 입력 → 컬러형 선택 경로 확인.
- 네 개 예시 HTML을 390/768/1440px에서 확인: 가로 넘침 없음, 모든 헤더 sticky, 연구형 논문은 작은 화면 한 열/큰 화면 두 열.
- 이미지가 있는 논문은 큰 화면에서 가로로 넓게, 모바일에서는 같은 내용이 세로로 표시된다.

## 사진·CV 단계 추가

- 순서: 기본 정보 → 자료 준비 → 사진·CV → 디자인 → 편집·게시.
- 기존 관리 화면 팔레트(화이트 #ffffff, 페이퍼 #f8f9f8, 차콜 #2a2a2a, 그린 #355b49, 구분선 #dfe3df)와 Pretendard를 유지한다.
- 레이아웃: 제목/단계 → 작은 사진 미리보기와 업로드 → 언어별 CV 파일 행 → 디자인으로 이어지는 버튼.
- 둘 다 선택 사항이다. 사진 없는 상태도 즉시 다음으로 넘어간다. 빈 파일 영역을 공개 페이지에 만들지 않는다.
- 기존 사진 확인/자르기와 PDF 검증을 재사용한다. 파일은 즉시 프로젝트에 반영하고, 창을 닫으면 현재 단계를 유지한다.
- CV는 기존 섹션·본문·링크를 보존한다. 새 섹션이 필요하면 연락처 앞에 만들며, 언어 간 파일 공유는 직접 선택한다.
- 처음 만들 때만 자동 안내한다. 기존 프로젝트도 편집 도구의 사진·CV에서 다시 열 수 있다.
- 검토: 사진을 받은 상태에서 네 디자인을 비교할 수 있고, 기존 파일을 다시 제출할 필요가 없다. 설명은 선택 여부와 공개 위치를 알려주는 정도로 제한한다.

### 사진·CV 검증

- 앱 검사 215개, 게시 서버 검사 12개, Worker 사전 확인 통과.
- 실제 브라우저에서 AI 답변 반영 → 사진 업로드 → CV 업로드 → 컬러형 미리보기 → 편집 흐름 확인.
- 영문 CV를 한글에 연결한 뒤 영문 파일만 삭제해도 한글 CV가 남는지 확인. 잘못된 PDF를 선택해도 기존 파일 유지.
- 창을 닫고 홈에서 다시 열었을 때 사진·CV와 진행 단계 유지. 편집 도구에서도 같은 파일 확인.
- 사진 변경에서 Escape를 누르면 상위 사진·CV 화면으로 복귀. 사진·CV 없이 건너뛸 때 빈 CV 섹션이 생기지 않음.
- 390px 화면에서 모달 가로 넘침 없이 표시되고 하단 진행 버튼 접근 가능. 브라우저 오류 없음.
