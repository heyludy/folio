# 섹션 기본 디자인 · 2026-09-17

내용에 맞는 기본 배치를 적용했습니다. 별도 디자인 선택 단계는 추가하지 않았으며 텍스트·항목·사진의 자유 크기 조절은 유지합니다.

| 섹션 | 기본 배치 |
| --- | --- |
| 연구 프로젝트 | 사진과 소개, 연구 상태·역할·지원기관·공동연구자를 묶은 카드 |
| 저서 | 표지와 책 소개를 나란히 배치 |
| 언론·인터뷰 | 이미지, 기사 제목, 소개, 원문 링크 |
| 발표·강연 | 날짜, 발표 소개, 장소·영상·발표자료 구분 |
| 새 소식 | 날짜 중심의 간결한 목록 |
| 모집 안내 | 마감일·모집 상태·지원 조건을 담은 공고 |
| 자료·도구 | 설명과 버전·라이선스·다운로드 구분 |

공통 `SitePage`와 내보내기 CSS를 사용하므로 편집 화면, 미리보기, 새로 내보내거나 게시하는 HTML에 함께 적용됩니다. 기존 게시 사이트는 다시 게시해야 변경됩니다.

## 검증

- `npm test`: 기존 186개 검사 통과.
- `npm run build`: 성공.
- `git diff --check`: 통과.
- 브라우저: 4개 템플릿 × 2개 언어 × 8개 너비(320·390·600·768·820·821·1040·1440px) × 기본/사용자 조정 크기 = 128개 조합에서 가로 넘침, 요소의 화면 이탈, 설명과 부가 정보의 겹침 없음.
- 크기 조정 예시: 항목 너비 55%, 제목 너비 80%·28px, 사진 600×420px. 모바일에서는 기존 반응형 크기 제한 적용.
- 모든 섹션에 부가 정보가 있는 항목과 없는 항목을 함께 배치. 사진·PDF가 없는 경우도 확인.
- 로컬 편집 화면에서 프로젝트 제목 크기 18→28px 변경 및 초기화 18px 복원 확인.

재현: `npm test && node scripts/build-section-fixtures.mjs` 실행 후 `../outputs/section-designs/`를 HTTP 서버로 열고 **Check all sections**를 누릅니다. 테스트 파일은 가상 내용으로 생성하며 저장된 프로젝트나 운영 게시물은 읽거나 수정하지 않습니다.
