## 검증 범위와 남은 한계

- 브라우저 검사는 Codex 내장 Chromium에서 수행했습니다. iOS Safari·Android 실제 기기 검증은 포함하지 않습니다.
- 실제 PDF 뷰어 새 탭 접근은 앞선 브라우저 검사에서 도구 보안 정책에 의해 차단됐으며, 운영체제의 파일 선택 창도 자동 확인 범위에서 제외했습니다. PDF 헤더·용량·언어별 파일·HTML 포함·Blob 생성 및 다운로드 핸들러는 코드 검사로 확인했습니다.
- 이번 순서 이동 UI 검사는 위·아래 버튼으로 수행했습니다. 드래그 위치 계산과 재정렬은 기존 코드 검사 범위입니다.
- 편집 저장은 여전히 같은 브라우저·주소 안에서만 공유됩니다. 다른 기기나 담당자의 브라우저와 자동 동기화하는 기능은 없습니다.
- 업데이트 후 열린 Folio 탭을 모두 새로고침하고, 공개 HTML도 다시 내보내야 새 동작이 적용됩니다.
