## 주요 기능

| 기능 | 내용 |
| :--- | :--- |
| **AI 자료 준비** | 프롬프트 복사 → MD 업로드·붙여넣기 → 페이지로 확인 후 반영 |
| **직접 편집** | 페이지에서 글을 수정하고 사진·텍스트 크기 조절 |
| **자유로운 구성** | 섹션과 항목 추가·삭제, 드래그로 순서 변경 |
| **언어 선택** | 영어 전용 또는 영어·한글 페이지 구성 |
| **디자인 선택** | 실제 사이트·대학 팔레트를 참고한 5가지 테마와 5가지 폰트 조합 |
| **파일 업로드** | 프로필·연구 이미지와 CV·논문 PDF 첨부 |
| **홈페이지 게시** | 기본 주소로 게시·재게시·중단, 구매한 도메인 연결 (게시 서버 연결 필요) |
| **HTML 내보내기** | 모바일 대응, 스크롤 등장 효과, 이메일·웹 링크 포함 |

소개, 연구, 논문, 학력, 연락처를 기본으로 시작합니다. 수상, 저서, 강의, 프로젝트, 연구실, CV 등 필요한 섹션을 더할 수 있어요. 기본 섹션도 자유롭게 지우거나 옮길 수 있습니다.

현재는 **기본형 템플릿**을 제공합니다. 사이드바형 · 연구 중심형 · 저서·미디어형은 추가 예정입니다.

## 사용 방법

1. **프로젝트 만들기** — 템플릿 → 언어 → 이름·소속 순서로 선택·입력합니다.
2. **내용 준비·편집** — AI용 프롬프트와 MD 가져오기로 채우거나, 페이지를 직접 눌러 수정합니다.
3. **미리보기 → 게시** — 기본 주소로 공유하거나 구매한 도메인을 연결합니다. HTML 파일로도 다운로드할 수 있어요.

홈에서 여러 교수님의 프로젝트를 관리하고, 삭제한 프로젝트는 목록에서 복원할 수 있습니다. 내보낸 HTML은 편집기 없이 독립적으로 동작합니다.

> **저장 안내** · 로그인 없이 현재 브라우저에 자동 저장됩니다. 다른 기기·사용자와 자동 공유되지 않으며, 브라우저 데이터를 지우면 초안도 삭제됩니다. 다운로드한 HTML은 공개용 결과물이며 편집용 백업은 아닙니다.

Google 로그인·공용 프로젝트 저장은 연결 설정 후 사용할 수 있습니다. 허용된 구성원 모두 같은 프로젝트를 관리해요. [연결 가이드](docs/cloud-workspace.md)
