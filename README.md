## 주요 기능

| 기능 | 내용 |
| :--- | :--- |
| **공용 프로젝트** | Google 로그인 후 구성원 모두 같은 프로젝트 편집·저장 |
| **수정 이력** | 이전 페이지 미리보기·복원, 최근 수정한 사람과 시간 확인 |
| **프로젝트 복제** | 내용·사진·PDF를 복사해 별도 프로젝트로 시작 |
| **AI 자료 준비** | 프롬프트 복사 → MD 업로드·붙여넣기 → 페이지로 확인 후 반영 |
| **직접 편집** | 페이지에서 글을 수정하고 사진·텍스트 크기 조절 |
| **자유로운 구성** | 섹션과 항목 추가·삭제, 드래그로 순서 변경 |
| **언어 선택** | 영어 전용 또는 영어·한글 페이지 구성 |
| **디자인 선택** | 4가지 템플릿, 7가지 테마, 5가지 폰트 조합 |
| **파일 업로드** | 프로필·연구 이미지와 CV·논문 PDF 첨부 |
| **홈페이지 게시** | 기본 주소로 게시·재게시·중단, 구매한 도메인 연결 (게시 서버 연결 필요) |
| **초안 공유** | 로그인 없이 보는 7일 검토 링크, 새 버전 공유·링크 종료 |
| **게시 변경 요약** | 소개문 전후 비교, 논문·파일·언어·배치 변경을 게시 전에 확인 |
| **게시 전 점검** | 링크·이메일 형식, 미등록 파일, AI 확인 메모를 살펴보고 수정 위치로 이동 |
| **화면별 미리보기** | 공개 HTML로 모바일·태블릿·데스크톱 확인, 320~1920px 너비 직접 지정 |
| **HTML 내보내기** | 모바일 대응, 스크롤 등장 효과, 이메일·웹 링크 포함 |

소개, 연구, 논문, 학력, 연락처를 기본으로 시작합니다. 수상, 저서, 강의, 프로젝트, 연구실, CV 등 필요한 섹션을 더할 수 있어요. 기본 섹션도 자유롭게 지우거나 옮길 수 있습니다.

**기본형 · 소개형 · 컬러형 · 연구형**을 내 자료로 비교하세요. 편집기 상단의 **템플릿**에서 언제든 바꿀 수 있고, 내용과 첨부파일은 유지됩니다. 색과 글꼴도 디자인별로 기억합니다. [네 가지 예시 보기](https://heyludy.github.io/folio/examples/)

## 사용 방법

1. **프로젝트 만들기** — 이름·소속·언어를 입력합니다. 공식 프로필 주소는 선택 사항입니다.
2. **자료 준비** — 생성된 프롬프트를 사용하는 AI에 전달하고, 완성된 MD 파일이나 답변을 가져옵니다.
3. **확인·디자인 선택** — 반영할 내용을 확인하면 페이지가 만들어집니다. 네 가지 템플릿을 내 내용으로 비교해 고릅니다.
4. **편집·미리보기** — 글을 직접 수정하고 사진·PDF를 추가합니다. 화면 크기별 확인과 초안 공유도 가능합니다.
5. **게시** — 기본 주소로 공개하거나 구매한 도메인을 연결합니다. HTML 파일로도 다운로드할 수 있어요.

홈에서 여러 교수님의 프로젝트를 관리하고, 삭제한 프로젝트는 목록에서 복원할 수 있습니다. 내보낸 HTML은 편집기 없이 독립적으로 동작합니다.

수정 이력은 프로젝트마다 최근 30개를 보관합니다. 이전 버전을 복원해도 공개 홈페이지는 바로 바뀌지 않으며, **변경사항 게시**로 반영합니다.

초안 링크는 생성 당시의 페이지를 공유하며 7일 뒤 만료됩니다. 새 링크를 만들거나 종료하면 이전 링크는 닫힙니다. 항목별 게시 비교는 이 기능 도입 후 게시한 버전부터 제공됩니다.

> **저장 안내** · 운영 사이트는 Google 로그인 후 공용 공간에 자동 저장됩니다. 에이퍼브 회사 계정과 등록된 관리자 계정으로 이용할 수 있어요. 기존 브라우저 자료는 홈의 ‘이 브라우저 프로젝트 가져오기’로 옮깁니다. 수정한 홈페이지는 ‘재게시’를 눌러 공개 사이트에 반영하세요.

직접 설치할 때 클라우드 연결 설정이 없으면 현재 브라우저에만 저장됩니다. 다운로드한 HTML은 공개용 결과물이며 편집용 백업은 아닙니다. [클라우드 연결 가이드](docs/cloud-workspace.md)

## 로컬 실행

```sh
npm ci
npm run dev
```

검사: `npm test` · 배포 빌드: `npm run build`

`main`에 푸시하면 GitHub Actions가 검사·빌드 후 GitHub Pages에 배포합니다.
