# Folio

로그인 없이 사용하는 React 관리자와 독립된 HTML 홈페이지 생성기를 분리한 프로토타입입니다.

## 실행

```sh
npm ci
npm run dev
```

`npm run build` 결과인 `dist/`가 관리자 배포 파일입니다. Vite의 상대 경로 설정으로 저장소 하위 경로에도 배포할 수 있습니다. GitHub Pages용 `.github/workflows/pages.yml`이 포함되어 있습니다. main 브랜치에 올리면 검사·빌드 후 dist를 배포합니다.

## 관리 기능

- 프로젝트 카드 홈에서 여러 사이트 생성·열기·전환, 브라우저 자동 저장
- 새 프로젝트 생성 시 템플릿 → ‘영어만 / 영어 + 한글’ → 기본 정보 순서로 선택
- 편집기의 EN / KOR 탭에서 버전 전환. 없는 KOR 버전은 가운데 +로 추가
- KOR 옆 ×로 한글 버전 전체 삭제, 알림의 ‘되돌리기’로 복원. 영문 내용·공통 디자인 유지
- 기존 프로젝트의 기본 정보와 사용 언어는 상단 ‘기본 정보’에서 수정
- 한 번 입력한 이름·대학·학과·직함·연구실·이메일을 해당 위치에 채우기
- 이름과 대학·학과를 가져오는 간결한 푸터
- 페이지에서 직접 글 편집, 사진 업로드·삭제
- 한글·영문 내용 분리, 대학·학과·직함 개별 편집
- 모든 섹션 추가·삭제·숨김·순서 변경·메뉴 포함 설정, 삭제 직후 되돌리기
- 그립 드래그, 여백 길게 누르기, 위·아래 버튼으로 순서 변경
- 텍스트·사진·연구/논문 항목을 개별 선택하여 크기 조절. 방향키 및 초기화 지원
- 텍스트 박스 너비·높이, 글자 크기(숫자 입력 또는 A 조절점) 변경
- 사진 너비·높이·비율 변경. ‘비율 고정’을 풀면 각각 조절
- 섹션은 내용 크기에 맞춰 자동 확장
- Font 선택과 5가지 배경색·포인트색 조합
- 미리보기에서 스크롤 등장 효과; 동작 줄이기 설정 존중
- 웹 편집기의 미리보기에서 전체 너비 / 태블릿 768px / 모바일 390px 전환
- HTML 내보내기: 공개할 내용만 정적 마크업으로 생성

- `src/studio.css`: 관리자 디자인

## 저장 및 전달

프로젝트 시작 시 고르는 템플릿은 현재 **기본형** 하나입니다. 선택값은 프로젝트의 `template`에 저장하며, 기존 프로젝트처럼 값이 없으면 기본형으로 표시합니다. 사이드바형(고정 프로필과 옆 본문), 연구 중심형(대표 연구·프로젝트 이미지), 저서·미디어형(책·강연·인터뷰)은 **추가 예정**으로 표시하고 선택을 막습니다. 이 세 가지의 실제 페이지 레이아웃은 아직 구현하지 않았습니다.

영어 전용 프로젝트는 영문 입력만 보입니다. 두 언어를 선택하면 이름·대학·학과·직함·연구실 위치를 각각 입력하며 이메일은 공통입니다. 기본 정보에서 대학을 바꾸면 소개와 연락처에 함께 반영합니다. 직접 편집할 때도 기존 값이 동일한 대학·이메일은 동기화하며, 이전에 서로 다르게 적은 값은 유지합니다. 소개 문장 자체를 자동 번역하거나 바꾸지는 않습니다. 푸터는 현재 언어의 이름·대학·학과에서 생성되어 별도 수정이 필요 없습니다.

기존 저장 데이터에 언어 설정이 없으면 이전처럼 두 언어를 유지합니다. 기본 정보에서 한글 사용을 끄는 것은 내용 보관, KOR 옆 ×는 한글 내용 전체 삭제입니다. 삭제 직후 알림에서 복원할 수 있으며, 이 복원 기록은 새로고침하면 사라집니다. +로 새 한글 버전을 만들면 같은 섹션 구성과 디자인을 사용하고 이메일을 가져옵니다. 번역문은 직접 작성합니다.

섹션 전체 크기 조절은 제거했으며, 이전에 저장된 섹션 폭·여백 설정도 적용하지 않습니다. 섹션은 내용에 맞춰 자동으로 커집니다. 텍스트·개별 항목의 너비, 최소 높이와 글자 크기는 언어별로 저장합니다. 내용이 박스보다 길어져도 자르지 않습니다. 프로필 사진 크기와 비율은 두 언어에서 공유하고, 선택 섹션의 사진은 언어·항목별로 저장합니다. 작은 화면에서는 컨테이너에 맞게 줄입니다. 사진은 지정한 비율을 채우도록 잘라 보입니다. 기존 localStorage 초안은 첫 실행 시 IndexedDB로 이관합니다. 이전 원본 키는 지우지 않으며, 이후 저장·불러오기는 IndexedDB를 사용합니다.

## 공개 페이지의 반응형

완성된 교수님 홈페이지와 내보낸 HTML에 적용합니다. 웹 편집기의 미리보기 역시 같은 CSS를 사용하며, 브라우저 전체 폭이 아닌 페이지 자체의 폭을 기준으로 반응합니다.

- 600px 이하: 접이식 메뉴, 이름·사진 옆 배치와 그 아래 전체 너비 소개문, 연구 항목 1열, 세로 푸터
- 좁은 논문·수상 목록: 연도를 제목 위로 배치
- 900px 이하: 과도하게 좁은 글 박스는 읽을 수 있는 너비로 확장하고, 수동 최소 높이와 큰 글자 크기를 화면에 맞춰 제한
- 사진 비율 유지, 긴 소속·이메일 줄바꿈, 넓은 화면에서는 최대 1060px의 중앙 정렬
- 접이식 메뉴는 항목 선택·Escape로 닫기 지원. 자바스크립트가 꺼져 있으면 메뉴 링크를 펼쳐 표시

저장한 크기 값 자체는 바뀌지 않습니다. 큰 화면으로 돌아오면 지정한 크기를 다시 사용합니다. 모바일에서도 본문은 높이에 따라 잘리지 않고 섹션이 늘어납니다.

검증용 정적 HTML은 `npm test` 후 `node scripts/build-responsive-fixtures.mjs`로 생성합니다. 상위 `outputs/responsive-preview.html`에서 기본 예시, 큰 요소·긴 이름, 사진 없는 영문 전용 예시를 여러 폭으로 확인할 수 있습니다. 실제 저장 프로젝트에는 접근하지 않습니다.

로그인은 없습니다. 저장 범위는 **현재 브라우저·주소**이며, 관리자 URL을 다른 사람에게 전달해도 편집 내용은 자동 공유되지 않습니다. 담당자 간 공유 저장은 별도 서버 저장소를 연결할 단계입니다. 브라우저 데이터를 지우면 초안도 지워집니다. 현재 HTML 출력은 공개 사이트 결과물이며, 관리자 초안을 복원하는 백업 파일은 아닙니다.

내보낸 HTML에는 관리자 UI, 편집 기능, React 실행 코드가 포함되지 않습니다. 선택한 언어의 내용과 색·폰트·스크롤 효과가 포함됩니다. 영어 전용이면 한글 내용과 언어 전환 버튼을 출력하지 않습니다. 자바스크립트가 꺼져 있어도 영문 콘텐츠가 보이며, 언어 전환, 등장 효과, PDF 보기·다운로드에 작은 스크립트를 사용합니다. 자바스크립트가 꺼져 있으면 PDF 보기 링크가 다운로드로 동작합니다. 숨긴 섹션, 빈 항목은 출력하지 않습니다.

웹폰트와 초기 예시의 공식 프로필 사진은 외부 주소를 사용하므로 인터넷 연결이 필요합니다. 관리자에서 직접 올린 JPG/PNG/WebP 사진은 HTML에 포함됩니다. 사진 원본은 2MB 이하로 제한합니다.

공개 사이트 도메인과 관리자 도메인은 서로 독립적으로 연결할 수 있습니다. 자동 배포·DNS 확인·도메인 연결 API는 아직 구현하지 않았습니다. GitHub Pages는 서버 저장/API를 대신하지 않습니다.

허은녕 교수 예시 출처와 문구 작성 기준은 상위 `outputs/eunnyeong-heo-content-sources.md`에 있습니다.

## 목록 항목과 공개 링크

수상·학력·경력·연구·논문 등 목록형 섹션의 아래쪽에 항목 추가 버튼이 있습니다. 새 항목은 현재 언어에만 추가하며 제목에 바로 입력할 수 있습니다. 각 항목의 ×로 삭제합니다. 기존 두 항목 데이터와 개별 크기 설정, 학력·경력을 긴 글로 적은 데이터는 유지합니다. 새 항목의 안정적인 ID와 언어별 순서를 저장하며 빈 항목은 미리보기·HTML에서 제외합니다. 한글 페이지 삭제·복원에도 항목 목록이 함께 반영됩니다.

공개 페이지에서 이메일은 mailto 링크, 입력한 HTTP(S)·www 웹주소는 웹 링크, 연구실 주소는 지도 검색 링크로 표시합니다. 편집 중에는 원래처럼 글을 직접 수정합니다. 링크는 메일을 자동 발송하지 않고 메일 작성 창만 엽니다.

등장 효과는 섹션과 목록 항목이 화면에 들어올 때 투명도·위치를 바꿉니다. 첫 화면의 시작 상태를 그린 뒤 관찰을 시작하며, 언어를 바꿨다가 돌아와도 재생합니다. 운영체제의 동작 줄이기 설정은 존중합니다. HTML에는 필요한 실행 함수를 직접 전달하여 React나 외부 앱 실행 코드에 의존하지 않습니다.

## 선택 섹션과 PDF

`+ 섹션 추가 → CV · 이력서 PDF → CV PDF 추가`에서 PDF를 선택합니다. 학력(Education)과 별도 섹션입니다. 영어·한글 PDF를 각각 등록·교체·삭제할 수 있습니다. 공개 페이지에는 보기·다운로드와 업로드 날짜가 나오며, 빈 섹션은 숨깁니다. 교수님의 실제 CV가 없는 상태에서 임의 문서를 넣지 않습니다.

- 논문: 저자·학술지, 게재 상태, 초록 펼치기, DOI·원문 링크, PDF
- 저서: 표지, 저자·출판사, 소개, 출판사·구매 링크
- 프로젝트: 이미지, 기간, 상태, 역할, 지원기관, 공동연구자, 링크
- 강의: 과목·학기, 기관, 학부·대학원, 강의 사이트, PDF
- 연구실·지도학생: 사진, 이름, 역할·과정, 재학·졸업, 연구 주제, 개인 링크
- 모집: 마감일, 지원 방법, 상태, 대상·연구 분야, 지원·문의 링크
- 발표: 행사, 장소, 발표 유형, 영상·행사 링크, PDF
- 언론: 이미지, 매체, 유형, 요약, 원문·영상 링크
- 자료: 유형, 버전, 이용 조건, 저장소·다운로드 링크, PDF
- 작품·전시: 작품 이미지, 연도, 설명, 전시명·장소, 작품·영상 링크
- 수상·활동·경력·소식: 항목 추가·삭제와 관련 정보
- 자유 소개: 본문, 이미지, 링크

세부 입력은 각 항목의 ‘세부 정보’를 펼쳐 페이지 안에서 수정합니다. 추가 이미지도 마우스·키보드로 크기와 비율을 조절할 수 있습니다. 빈 필드·파일은 공개하지 않고, 항목 삭제 시 해당 이미지·PDF·상세 정보도 함께 제거합니다. 영상은 외부 링크로 연결합니다.

PDF는 10MB 이하(파일 헤더 확인), 사진은 JPG/PNG/WebP 2MB 이하입니다. 업로드된 파일은 브라우저의 IndexedDB에 프로젝트와 함께 저장하고, HTML에는 포함하여 별도 파일 서버 없이 쓸 수 있습니다. 저장은 여전히 현재 브라우저·주소에 한정하며 서버 공유 저장이나 백업·불러오기 UI는 이번 범위에 없습니다.

## 기본 섹션과 삭제

소개·연구 분야·주요 논문·학력·연락처는 새 프로젝트에 미리 배치하는 기본 구성입니다. 위치나 삭제를 잠그지 않으며, 기존 초안의 `fixed` 값도 제한으로 사용하지 않습니다. 기본 섹션을 지운 뒤 `+ 섹션 추가`에서 다시 넣을 수 있고, 모두 지워도 빈 화면의 추가 버튼으로 다시 구성할 수 있습니다.

왼쪽 목록의 × 또는 섹션 도구의 ‘삭제’로 섹션 전체(영문·한글 내용, 항목, 이미지, PDF, 크기 설정)를 삭제합니다. 하단 ‘되돌리기’는 마지막 삭제를 원래 위치에 복원합니다. 새로고침하면 되돌리기 기록은 사라집니다. 기본 정보는 별도로 유지하여 소개·연락처를 삭제해도 프로젝트 이름이나 공통 정보 입력을 잃지 않습니다. 프로필 사진과 상세 약력은 섹션을 복원할 때 돌아옵니다.

섹션 추가는 화면 반영 이후 편집 캔버스 내부를 부드럽게 스크롤하고 제목에 포커스를 둡니다. 페이지 맨 아래에도 추가 버튼이 있으며, 목록 항목 추가도 같은 방식으로 이동합니다. 운영체제의 동작 줄이기 설정에서는 즉시 이동합니다.

추가 검증: 39개 검사 통과. 별도 테스트 프로젝트에서 스크롤 0 → 약 2147px 이동과 제목 포커스, 바깥 페이지 스크롤 유지, 섹션 삭제·복원, 기본 섹션 이동·삭제, 전체 삭제 후 재추가, 재접속 후 보존을 확인했습니다.

## 자체 QA 후 보완

- 섹션 제목을 수정하면 공개 메뉴도 현재 언어의 제목을 사용합니다. 이름을 담는 소개 섹션의 메뉴는 About / 소개를 유지합니다.
- 내보낸 HTML은 `#ko`, `#en`, 한글·영문 섹션 주소를 읽어 해당 언어와 위치를 복원합니다. 새로고침과 뒤로·앞으로 이동에도 적용됩니다.
- IndexedDB 저장은 한 트랜잭션 안에서 최신 초안과 이 탭의 기준 초안을 비교합니다. 서로 다른 항목 수정은 병합하며, 같은 항목 수정이나 삭제/수정 충돌은 저장을 중단합니다. 충돌 시 로컬 편집 내용은 화면에 유지하고 HTML 보관·최신 저장 내용 불러오기를 제공합니다.
- 저장 실패 시 다시 저장할 수 있으며, 미저장 내용이 있는 탭을 닫을 때 브라우저 확인이 표시됩니다.
