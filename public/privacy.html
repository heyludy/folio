Folio

개인정보 안내

Folio는 허용된 구성원이 교수님 홈페이지를 함께 만들고 관리하는 도구입니다.

업데이트: 2026년 9월 16일

로그인 정보

Google 로그인으로 전달되는 계정 식별자, 이메일, 이름, 프로필 사진과 이메일 확인 정보를 인증 서비스인 Supabase에서 처리합니다. Folio는 계정 식별자와 확인된 이메일을 사용해 접근 권한을 확인하고 수정한 사용자를 기록합니다.

로그인에는 기본 계정 정보 권한만 요청합니다. Google 비밀번호를 전달받지 않으며 Gmail, Drive, Calendar 자료에 대한 권한은 요청하지 않습니다.

공용 프로젝트와 공개 홈페이지

  • 프로젝트 내용, 사진, PDF와 게시 연결 정보를 공용 저장소에 보관합니다. 허용된 모든 구성원이 같은 프로젝트를 열고 수정할 수 있습니다.
  • 편집 중인 자료와 첨부 파일은 로그인과 권한 확인을 거쳐 제공합니다.
  • 게시하면 홈페이지 내용과 포함된 사진·PDF가 인터넷에 공개됩니다. 게시 중단은 공용 프로젝트 삭제와 별도 동작입니다.

저장과 서비스 제공

Google은 계정 인증, Supabase는 로그인과 데이터·파일 저장, Cloudflare는 게시와 도메인 연결, GitHub Pages는 편집기 제공에 사용됩니다. 연결된 Supabase 프로젝트는 일본 도쿄 리전을 사용하며, 공개 홈페이지는 Cloudflare의 전 세계 네트워크에서 제공될 수 있습니다.

로그인 유지와 저장 실패 시 복구를 위해 브라우저 저장소에 세션과 임시 편집본을 보관합니다. 기존 브라우저 프로젝트는 사용자가 가져오기를 선택할 때 공용 공간으로 전송됩니다.

보관과 삭제

공용 프로젝트는 계속 관리할 수 있도록 저장합니다. 프로젝트를 삭제해도 휴지통에서 복원할 수 있도록 자료와 첨부 파일이 남습니다. 계정 또는 자료의 영구 삭제가 필요하면 아래 운영 연락처로 요청해 주세요. 계정 삭제와 이미 공개한 홈페이지의 게시 중단은 각각 확인해야 합니다.

공개한 정보는 검색엔진이나 공유 서비스의 캐시에 일정 기간 남을 수 있습니다.
